# Deliverables

The five things the brief asks for, and where each one is.

| # | Deliverable | Where |
|---|---|---|
| 1 | Code: a runnable private repo with setup and run instructions and a granular commit history | This repository. [README](../README.md) for setup and running; `git log` for the history. |
| 2 | Output table: the extracted records from the provided documents, with confidence flags and source references | [provided_output/records.csv](provided_output/records.csv), with the report, conflicts and review page beside it. [provided_output/README.md](provided_output/README.md) explains the columns. |
| 3 | Agent-generated summary of the conversation with the agent, highlighting the author's role | [docs/agent-log.md](../docs/agent-log.md), written by the agent session by session. |
| 4 | Write-up, one page, covering the nine points | [Google Doc](https://docs.google.com/document/d/1gmsndGzRHyr89st2KK78ba6leFMsBOOoV5MXLR5z55Q/edit?usp=sharing), shared with the reviewers. |
| 5 | Video walkthrough, under five minutes | Sent with the submission; not committed, at 20 MB. |

Supporting material a reviewer may want next: [docs/walkthrough.md](../docs/walkthrough.md) (one run, start to finish), [docs/how-it-works.md](../docs/how-it-works.md) (the mechanism), [docs/schema.md](../docs/schema.md) (the schema and why), [PLAN.md](../PLAN.md) (the design as built), [evals/reports](../evals/reports) (every evaluation run).
